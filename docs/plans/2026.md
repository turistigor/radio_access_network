# План реализации roadmap 2026

## MVP реализация различных способов с взаимодействия внутри системы
- Создание микросервиса фронтенда, отдающего статику "It works";
- Ручки на backend с заглушками для фронтенда:
  - получить список устройств (одно устройство);
  - установить статус конкретного устройства;
  - получить статус конкретного устройства;
  - запустить телеметрию;
  - остановить телеметрию.
- Создание элементов управления, взаимодействующих с backend-ом:
  - список доступных устройств,
  - команды к устройству,
  - запрос состояния устройства,
  - отображение телеметрии.
- Создание микросервиса учета устройств:
  - зарегистрировать устройство;
  - отменить регистрацию устройства;
  - выдать список устройств;
  - получить статус устройства;
  - установить статус устройства;
- Создание симулятора устройства:
  - регистрация в менеджере;
  - включение/выключение;
  - запуск/остановка телеметрии (изменение статуса, без потока данных).
- Масштабируемое WebSockets соединение backend-frontend;
