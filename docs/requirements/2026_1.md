# Реализация различных способов с взаимодействия внутри системы

## Функциональность
- F1: Реализовать передачу команд от интерфейса пользователя имитаторам устройств.

## Удобство использования
- U1: Интерфейс должен отображатсья в браузере и содержать элементы:
  - список доступных устройств,
  - команды к устройству и способ их отправить,
  - состояние устройства,
  - отображение телеметрии.

## Надежность
- R1: Все операции, производимые в интерфейсе, должны корректно работать с возникающими ошибками.
- R2: Все механизмы передачи сообщений в системе должны быть спроектированы с учетом возможных ошибок.

## Производительность
- Задержка при выполнении операций в интерфейсе не должна составлять более 1 секунды.
- Частота отображения телеметрических данных от каждого устройства должна быть не хуже 1 секунды.

## Поддерживаемость
- Все механизмы обмена дынными должны быть приспособленны к изменению числа устройств.

## Ограничения реализации
- Для реализации должны быть применены следующие технологии:
  - Kafka
  - REST API
  - WebSockets
  - gRPS
